# Smart Hospital & Resource Allocation System

## CSC 1012 - Introduction to Computer Programming

University of Sri Jayewardenepura  
Faculty of Applied Sciences

## Project Description

A modular, menu-driven Smart Hospital Patient & Resource Allocation
System implemented in the C programming language.

## Features

- Patient registration
- Emergency triage
- Doctor specialty selection
- Hospital bed allocation
- Waiting-time estimation
- Medical billing
- Priority-based patient sorting
- Performance reports

## Technologies

- C Programming Language
- Git
- GitHub
